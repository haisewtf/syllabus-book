# 📖 WEB бағдарламалау — 3D силлабус-кітап

Интерактивная 3D-книга с силлабусом по дисциплине «WEB бағдарламалау» (КазАТИУ им. С. Сейфуллина, 6В06101 «Бағдарламалық инженерия»).
Книга лежит в тёмном зале с лампой, камином, окнами и книжными шкафами. Страницы перелистываются с реалистичным изгибом и звуком.

> Чистый HTML + CSS + JavaScript. Без сборки, без зависимостей, без `npm`.

## ✨ Возможности

- 3D-книга с толстым блоком страниц, корешком и золотым тиснением
- Плавный изгиб страниц при перелистывании (CSS 3D, 6 сегментов на лист)
- Синтезированные звуки (Web Audio API): шелест страниц, скрип и удар обложки
- Комната: стены, потолок, ковёр, окна, камин, свечи, летающая пыль
- Управление: вращение мышью/пальцем, колесо — масштаб, стрелки ← → — страницы
- Оглавление, кнопки «Алдыңғы / Келесі», сброс вида, переключатель звука
- Учитывает `prefers-reduced-motion`

## 🚀 Запуск локально

Просто откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari).
Интернет нужен только для шрифта PT Serif с Google Fonts; без него подставится Georgia.

## 🎮 Управление

| Действие | Как |
|---|---|
| Повернуть сцену | Зажать и тянуть мышью / пальцем |
| Масштаб | Колесо мыши |
| Листать | Клик по странице, стрелки ← →, кнопки внизу |
| Оглавление | Выпадающий список внизу |
| Сбросить вид | Кнопка «⟲ Көрініс» |

## 🌐 Публикация на GitHub Pages

1. Залейте репозиторий на GitHub (инструкция ниже).
2. Откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
4. Branch: `main`, папка `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`.

## 📤 Как загрузить проект на GitHub

### Способ 1. Через сайт (проще всего)

1. Зайдите на https://github.com и войдите в аккаунт.
2. Нажмите **+ → New repository**.
3. Имя репозитория, например `web-syllabus-book`. Тип — Public. Нажмите **Create repository**.
4. На странице нового репозитория нажмите **uploading an existing file**.
5. Перетащите `index.html` и `README.md` (сами файлы, не архив).
6. Внизу нажмите **Commit changes**.

### Способ 2. Через Git (терминал)

```bash
cd web-syllabus-book
git init
git add .
git commit -m "Initial commit: 3D syllabus book"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/web-syllabus-book.git
git push -u origin main
```

Если Git просит пароль, используйте **Personal Access Token** (Settings → Developer settings → Personal access tokens) вместо пароля.

### Как обновлять потом

```bash
git add .
git commit -m "Описание изменений"
git push
```

## 🛠 Настройка

Всё в одном файле `index.html`, в блоке `<script>`:

- `const T=78` — толщина книги
- `NS=6` — число сегментов страницы (меньше = быстрее, больше = плавнее изгиб)
- массивы `lec`, `lab`, `srs`, `lit`, `P` — содержимое страниц
